# Archived LLM top-5 N-matrix configs

These YAMLs were the third M3 architecture before the freeze that replaced
LLM top-5 with **Jev top-1** as the control.

They are kept for historical / optional single-cell runs. They are **not**
part of the frozen M3 matrix under `configs/matrix/`.

LLM router implementation remains in the codebase (`architecture: llm`).
